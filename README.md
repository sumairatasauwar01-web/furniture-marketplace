# Luma Furniture Marketplace

A responsive, single-page furniture marketplace prototype with browsing, categories, category photo management, login/signup, profile access, buying, selling, seller enquiries, cart, and wishlist interactions.

This prototype uses the browser's `localStorage` as its data layer. Accounts, listings, uploaded category photos, enquiries, cart items, and wishlist items remain available after refresh on the same device/browser.

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server:

```bash
npx serve .
```
